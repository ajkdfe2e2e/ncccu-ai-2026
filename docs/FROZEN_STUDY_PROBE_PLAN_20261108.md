# 冻结 CXformer 的检查级对照实验（2026-11-08）

目标是在旧融合线上 78.53 的用户反馈基准上寻找实际增益。上一轮完整融合权重训练
验证失败，本轮改变表征和训练单位。旧权重及 CSV 保留，不继承任何公开基准分数。

## 来源与固定输入

- 编码器：`m42-health/CXformer-base`，HF revision
  `f778e2ac267fdd651205e07b6fd1113754b146bb`。已有本地 safetensors，冻结全部参数。
- 来源：https://huggingface.co/m42-health/CXformer-base 及 https://github.com/m42-health/CXformer。
  另查阅 EVA-X、Google CXR Foundation、CheXFound；先验证已有且可直接加载的 CXformer。
- 使用随权重发布的处理器：RGB、逐通道直方图均衡、短边 518、中心裁剪 518，
  ImageNet mean/std。`do_hist_equalization=true` 来自模型实际配置，不能只依赖 README。
- 图像特征为最终 layernorm 后的 CLS 与其后所有 token 均值拼接，共 1,536 维。
  后者包含四个 register token；这是明确记录的固定实现，不称为纯 patch 均值。
- 训练仅使用原 train 的 30,344 张图 / 18,513 次检查 / 11,055 位患者。
  验证和测试在训练候选及最终分类头固定后才执行。测试元数据只用于推理和覆盖检查。

## 两种输入、固定训练

1. `mean`：同一检查所有图像特征的均值。
2. `views`：AP/PA（包含 PA LLD）、LATERAL/LL、其他/空视图分别取均值并拼接，
   缺失组填零，再加三个存在标志，总维度 4,611。view 信息只来自每行 ViewPosition。

每次检查仅贡献一个训练样本。分类头使用训练折内估计的逐维标准化，十输出线性
logistic，CPU float64 LBFGS，固定 l2=0.01、max_iter=200、seed=20261108，
不加 pos_weight，不调阈值。损失为十类平均 BCE + 0.5*l2*sum(weight²)/10，偏置不罚。

沿用既有患者分组的 0/1/2/audit 四组；本轮所有组都是 train 内的交叉验证组，
原 audit 不再称独立保留集。每个分类头只在另外三组学习；编码器与最终部署始终相同。
旧配方的训练折外表仅作固定对照，不重新拟合旧融合系数。

## 固定选择与最终验证

共四个预定候选：两种输入，各自单模型（alpha=1）以及与旧配方固定
`0.8*old + 0.2*new`（alpha=0.2）。不会逐类改变旧权重。
只允许训练折外总体十类 Macro-AUC 增益 >=0.001，且至少三组增益 >0 的候选晋级。
从晋级候选中选总体 Macro-AUC 最高者，完全相同时优先 alpha=0.2，其次 mean。
该 OOF 结果参与有限候选选择，不冒充嵌套验证或无偏泛化估计。

选中后在全 train 的检查特征上重拟合小头，保存后精确重载，先登记最终 head 和
recipe SHA-256，再比较同一官方 valid。只比较选中的一个候选，不能根据 valid
重新选择输入、alpha、l2 或逐类回退。

最终保留条件：十类 AUC 均定义，Macro-AUC 增益 >=0.001；1,000 次患者配对
bootstrap 描述性 95% 差值区间下限 >0，至少 950 次有效。失败保留旧提交。
通过才提取测试特征，并按已锁定分类头和 alpha 导出单独的新 CSV。

## 可复现性与限制

锁定代码快照、环境、模型/处理器、CSV、患者分区、旧折外表及配方、旧 valid/test
预测的指纹。图像路径/大小/mtime 清单随阶段校验；不是所有图像内容的 SHA。
特征缓存记录固定行序、形状、已完成游标，完成批次写盘后才提交进度；恢复核对输入。
输入 batch=2，预处理使用最多两个线程、最多两个待处理批次，按原始行序交给 GPU；
正式启动前核对与串行预处理的真实图像特征逐元素一致，不改变预处理或推理批次。
真实图小样本只做工程验证，不进入正式选择。

公开模型训练涉及 MIMIC-CXR、CheXpert 等，是否与匿名比赛数据重叠未知。保留公开
来源和 CC BY-NC-4.0 / research-only 声明。旧配方和 valid 有历史选优偏差，最终
比较仍不是无偏泛化或线上提升保证。线上实测前不能宣称超过 78.53。
