# 当前 CXR-LT 模型的固定患者聚合实验（2026-11-08）

## 假设与历史来源

在同一患者的不同检查之间，固定、轻度的概率收缩可能减少噪声，同时保留检查之间的差异。本轮只验证一个候选：对同患者的检查概率取等权均值（包含当前检查），再计算 `q = 0.75 * p + 0.25 * patient_mean(p)`；十类使用同一系数。只有一次检查的患者输出保持原值。不使用时间推测、标签、按类参数、视图权重或阈值搜索。

系数 0.25 来自 2026-11-04 旧基线的 valid-only 探索，旧结果从 0.7806561630 到 0.7848800212。该探索复用了同一个官方 valid；它是明确的历史选优来源，不能称为从未观察过 valid 的新假设。本轮不在当前预测上重新搜索系数，当前模型的完整患者 OOF 与固定验证门槛决定是否接受这一候选，bootstrap 仅作描述性证据。

官方 2026-10-27 补充说明第 7 节允许利用官方患者分组进行确定性预测聚合，禁止借此拟合测试集参数或统计量，见 [规则核对](OFFICIAL_SCORING_20261108.md)。本轮保留原 CXR-LT 医学预训练来源，因此该后处理的允许性并不改变整体模型的预训练来源限制。

## 启动条件与不可变注册

先要求 `outputs/eva-study-probe-20261108-v2/experiment.json` 正常结束、未晋级、未导出测试 CSV，并要求独立 OOF 核验通过。比较基准保持 `outputs/cxrlt-supervised-study-probe-20261108`，train OOF Macro-AUC 0.8270384304066101、official valid 0.8335505264258105、用户反馈线上 78.98；旧融合比较值来自其已冻结产物。

真实评估前在全新输出目录注册 plan SHA-256、当前协议、执行源码快照和输入哈希。锁定当前模型的 plan/recipe/head/状态、完整 OOF IDs/targets/probabilities、当前 valid CSV、原始 train/valid/test manifests、患者四组划分、旧融合 OOF 组件和 prior/valid CSV、已完成 EVA 的状态/注册与独立核验。旧融合各组件原已锁定的 IDs/targets 一并复制核验。当前 test CSV 此时仅登记来源路径与既有 `submission_verification.json` 中的 SHA-256，不读取或复制预测文件；两项 valid 门槛通过后才复制并对照该预登记哈希。源脚本从冻结快照执行，不改旧模型、原 CSV、权重或既有实验。恢复只能使用同一计划；本轮不重新训练任何头或编码器。

## 单一候选的患者 OOF 门槛

按当前 OOF 中严格唯一的 `[subject_id, study_id]` 顺序处理全部 18,513 次检查，二值标签与十类概率逐项对齐。当前、旧融合及训练 manifest 的 ID 集合必须严格一对一匹配，显式重排后标签逐项相等；拒绝重复 ID、缺项、多项或冲突标签，不假定不同文件的行序相同。同患者必须仅属于四个固定患者组之一，保证患者均值不读取训练该患者预测的模型所见过的样本。

患者均值的池范围固定为当前 split：train OOF 只聚合 train OOF 检查，valid 只聚合 valid 检查，test 只聚合 test 检查。不得将同名患者的跨 split 预测合并；原始 manifest 的患者/检查身份需核验，拒绝冲突身份或官方患者划分中的跨 split 重叠。准备阶段仅读取 manifests 的身份和训练/验证标签，不读取或推测 test 标签。

对全部 held 预测执行固定聚合，保存完整候选 OOF。要求十类整体与每个 held 组的 AUC 全部可定义、相对当前与旧融合的整体 Macro-AUC 均增加至少 0.001，并在至少三组中超过当前。无此证据则正常结束，保留当前模型，不读取本轮 valid 概率计算指标，不导出新 test CSV。

该门槛有意保持与前一轮一致，允许一组回退；必须逐组报告，不能把整体或三组改善解释为所有患者组均受益。观察候选结果后不增加、降低或重定该门槛。

## 一次官方 valid 验证

OOF 门槛通过后，按原始 valid manifest 严格对齐当前模型 valid CSV，执行完全相同的固定患者聚合；与当前和旧融合在相同检查上分别比较。两次比较都要求十类 AUC 可定义、增加至少 0.001、seed=20261108 的 1,000 次患者配对 bootstrap 的描述性 95% 差值区间下界大于 0，且至少 950 次 replicate 有完整十类。任何一次失败即保留当前模型，不尝试其它系数或按类组合。

## 测试导出与独立核验

只有同时通过两项 valid 门槛才读取原始 test manifest 和当前已交付模型的 test 概率，执行固定患者聚合并导出 `submission_test_1414_cxrlt_patient025_20261108.csv`。不得读取或推测 test 标签、拟合任何测试参数或用测试分布调整方案。Gate 固定 0.5，严格校验 1,414 次检查 / 14,140 行 / 每次检查十类、唯一顺序、概率有限且在 [0,1]，保存后重放概率必须完全相等。

保存最终状态、plan/输入/源码/OOF/valid/test 产物哈希和评估报告。没有实际线上反馈时新候选 online_score=null；不能据本地结果承诺线上提升。现有线上最好文件和所有历史结果保留。本轮不自动提交比赛。
