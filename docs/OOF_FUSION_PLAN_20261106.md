# 训练集折外预测融合实验（2026-11-06）

目标是改进新患者上的检查级十类 Macro-AUC。保留原 0.820325 验证融合和已交付的 1414 检查测试 CSV。新实验的保留集与旧验证集不同，不能直接把两个分数相减来判断收益。

仅使用原 train.csv 的固定患者分区：8844 名开发患者、2211 名保留患者。复用正在执行的 `generalization-rad-dino-20261105-v2` 三折 A/raw 折外预测，固定分类头学习率 1e-3，其他训练参数与其 A 配置一致。融合不根据 A/B、EMA 结果更换主模型。原完整 train 微调检查点不能参与本轮融合输入。

固定五个外部冻结分支：itsomk DenseNet121、chest-xray-bench 的 rad_dino_vitB_768、medmae_vitb_nih_B_768_s2、medmae_vitb_nih_B_768_s2_seed1337，以及 RussellALA ConvNeXt。DenseNet 映射全部十类，其余分支仅参与各自公开分类头覆盖的类别。每个分支保持此前核对的预处理；每次检查先平均图像概率；不增加 TTA、阈值、校准或模型子集搜索。公开版本和文件指纹沿用 public_model_manifest.json，来源与许可声明继续保留。

每类融合权重非负且和为 1，未覆盖类别的模型权重严格为 0。从可用模型等权初始化，最小化正负样本概率差的 logistic 排序损失，并加入向等权收缩的 L2 项：temperature=0.1、l2=0.1、每类最多 32768 对、seed=20261106。样本对不足时使用全部组合；否则有放回固定抽样。优化器使用投影梯度与回溯，最多 300 次迭代、tolerance=1e-8。这是 AUC 的替代优化目标，不保证实际 AUC 增加。算法与参数在拟合前固定，不根据拟合指标重选。

所有融合学习只消费开发患者标签、主模型折外预测、公开冻结分支开发预测。融合 OOF 拟合分数只作训练诊断，不作为独立泛化成绩，也不使用“对已有 OOF 表再分折”的伪嵌套验证选配方。完整融合权重和输入指纹保存后才执行本轮保留集读取与推理。

当前训练实验可能先自动执行自己的保留集比较。融合协议必须在其 `audit_opened=false` 时注册，并在任何保留集成绩出现前固定代码、输入与参数。原训练改动与本轮融合构成两个预先声明的比较：各自相对新训练的 A/raw。最终统一重算 4000 次患者配对 bootstrap 的 97.5% percentile 区间，按两项比较作 Bonferroni 调整；即使某个结果不利也照常报告。原自动报告的 95% 标签不作为这组比较的最终确认结论。原训练候选未达到其开发晋级规则时，不执行该候选的保留比较，仍保留两个比较的保守校正。

融合比较要求 Macro-AUC 增量至少 0.001，且上述区间下界大于 0，才记录本轮保留集对收益的支持。每次抽样整簇保留同一患者的全部检查；任一类别缺乏正负样本的抽样不计入区间，4000 次中至少 3800 次有效才报告区间。等权融合仅作描述性对照，不能根据保留集结果改选它。不得在看到保留结果后修改配方。

原实验的 A/raw 开发集重训检查点如已存在且全部产物指纹一致，则安全复用；否则从公开初始化独立重训相同 A/raw。GPU 任务等待当前完整实验结束后串行执行，避免争用显存。新流程使用独立目录、代码快照、输入指纹与阶段完成校验；未完成阶段失败时保留现场并停止，不静默复用部分产物。
