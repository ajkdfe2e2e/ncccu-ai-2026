# ConvNeXtV2 冻结特征分类头的患者嵌套选参方案（2026-11-08）

本方案在本轮真实候选拟合和评分前写定。目标是在已完成的 CXR-LT 检查级模型上继续提高十类 Macro-AUC，同时控制追加搜索带来的选择偏差。仅复用已完成的 1,054 维图像特征缓存，使用 CPU 训练；不增加公开权重、不重新提取图像特征。

## 基线、数据与固定候选

- 当前基线：`outputs/cxrlt-supervised-study-probe-20261108` 的 `mean, alpha=1`、普通 BCE、L2=0.01。train OOF Macro-AUC 为 0.8270384304066101；官方 valid 为 0.8335505264258105。
- 同时保留旧融合基线：train OOF 0.8182590866984774，官方 valid 0.8203251712650804，用户反馈线上 78.53。新 CXR-LT 候选尚无线上成绩。
- 仅用用户 train 的 30,344 张图 / 18,513 次检查 / 11,055 位患者拟合。固定复用原患者组 0、1、2、audit；audit 现在是训练交叉验证组。
- 每个检查仍使用所有图像的 1,054 维特征均值。没有新的汇总模式、视图搜索或融合比例。
- 共六个固定配置：L2 ∈ {0.001, 0.01, 0.1} × {普通 BCE、类别加权 BCE}。
- 类别加权只从每次实际训练子集估计：`positive_weight = clip(sqrt(negative_count / positive_count), 1, 5)`。每类 unreduced BCE 除以该训练子集的平均样本权重 `(negative_count + positive_weight * positive_count) / N`，再对样本及十类取均值；沿用现有 L2 惩罚。预测保留训练所得原始 sigmoid，不另行修正偏置或调阈值。
- 两种损失的特征标准化、类别频率和初始化全部只用相应训练子集。固定 CPU float64、LBFGS、max_iter=300、seed=20261108、torch 线程数=4。普通 BCE 的现有默认数值路径保留。

## 外层只评价一套选参流程

1. 对四个外层患者组分别留出一组。它的特征、标签不进入该外层的参数拟合或参数选择。
2. 在剩余三个患者组内做三组交叉验证，分别计算六个固定配置的拼接内层折外十类 Macro-AUC。
3. 仅按内层 AUC 选择一个全局配置，不做逐类选择。精确并列时优先普通 BCE，其次更强的 L2。用剩余三个组拟合该配置，预测外层留出组。
4. 拼接四组外层预测，与当前 CXR-LT 和旧融合在同一检查上比较。外层门槛为：十类 AUC 全部定义、相对当前 CXR-LT 总体增益至少 0.001、至少四组中的三组增益为正，同时超过旧融合。
5. 相同训练组和配置的分类头可以缓存复用；缓存身份包含计划哈希、训练组及完整配置，并验证头文件哈希。缓存预测或评分不得让外层标签进入该外层内层选择。

缓存复用后，内层最多拟合 6 个不同双组训练集 × 6 个配置 = 36 个头，另有 4 个外层头；如晋级，完整 train 选参最多补充 20 个三组训练头，再拟合 1 个最终头，整轮最多 61 个不同拟合。

## 晋级、固定验证与导出

- 外层门槛失败，记录阴性结果，保留已完成的 CXR-LT 测试 CSV，不读取官方 valid 标签做新候选评分，不导出新测试 CSV。
- 外层通过后，在完整 train 的四组交叉验证上，从同样六个配置选择最终配置。这个最终选参分数属于选择证据，与外层选参流程评价分别报告。最终配置的训练 OOF 也需超过当前基线至少 0.001，否则停止。
- 使用全部 train 拟合一个最终分类头，保存重载并精确验证预测，登记配方和头哈希后，才读取官方 valid 标签。
- 只评估这一个固定候选。官方 valid 必须相对当前 CXR-LT 和旧融合的 Macro-AUC 均提高至少 0.001；两组 1,000 次固定种子的患者配对 bootstrap 的描述性 95% 差值区间下界均须大于零，至少 950 次有完整十类 AUC，才导出独立的新测试 CSV。
- 失败后不按 valid 逐类回退、追加正则参数或修改类别权重。F1@0.5 和各类 AUC 同时报告，不用 F1 上升替代 AUC 门槛。test 只做固定配方推理，无标签学习。
- 保留当前新旧模型、CSV、源码快照及公开来源。不自动提交比赛或推送仓库。

## 核验与解释范围

正式拟合前运行损失/患者隔离/内层选择/缓存篡改/晋级相关定向测试，并用一个已存在的普通 BCE 头做数值回归验证；该基线复现不用于新增参数选择。冻结执行源码、输入文件、软件环境及计划。保存每次拟合的训练患者组、样本数、配置、耗时和优化器迭代数。

嵌套过程只隔离本轮内层选参与相应外层患者。此前多轮研究已使用这些训练组和官方 valid，不能把本轮称为全新无偏独立验证。公开预训练与匿名本地数据是否重叠仍未知。bootstrap 区间只作描述性门槛；导出新 CSV 不等于线上提高。

参考：scikit-learn 官方 `Nested versus non-nested cross-validation` 示例解释参数选择与外层评价的区别；PyTorch `BCEWithLogitsLoss` 文档定义 `pos_weight`。本项目直接复用现有 PyTorch/NumPy 实现，不新增依赖。
