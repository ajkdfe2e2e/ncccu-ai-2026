## 完整融合学习

按患者/检查和类别顺序拼接完整 `(18513,8,10)` 折外输入。
ResNet18 和 Rad-DINO 两来源所有患者均须验证 train/held 不相交，
公共冻结分支按原始发布的类别覆盖填入，缺失头不允许获得权重。
每类采用旧完整配方权重 q0 作为先验，学习 `q=0.8*q0+0.2*v`，
v 为可用八来源的非负 simplex。本次允许本地来源与公开来源之间重新分配质量。

固定使用现有锚定配对 logistic 排序损失：temperature=0.1、l2=1.0、
pair_count=32768、seed=20261107、max_iter=300、tolerance=1e-8。
拟合一次，不做超参数搜索、分支筛选、阈值拟合或验证后逐类回退。
折外基础预测上的融合拟合指标仍是元模型训练指标，不是完整融合的独立折外分数；
不将复用基础折外表再分折包装为无偏嵌套验证。

## 比较与保留标准

最终配方保存并哈希后，才在本轮读取官方 valid 标签。把学习出的系数应用到
旧版保存的完整训练模型验证预测，与同一 859 次检查 / 228 位患者上的旧完整融合
比较。基础折外模型与原部署检查点的训练样本量、随机轨迹及累积细节存在差异，
这次系数迁移是否有效必须实际验证，不能继承旧 audit 分数。

固定门槛：十类 AUC 均有定义、Macro-AUC 增益至少 0.001，且 1,000 次患者配对
bootstrap 的描述性 95% 差值区间下限大于零（seed=20261107，至少 950 次有效）。
失败则保留旧提交。
通过后才基于旧部署模型已保存的 test 预测导出单独 CSV，先要求旧嵌套配方精确
重放已交付 CSV，再校验新文件覆盖、概率、Gate=0.5 和精确数值回读。

旧配方及既往研究已用过官方 valid；上述区间仅描述本次固定比较，不是无偏
显著性或线上提升保证。所有来源和指纹保留，不掩盖公开权重使用情况。
