# 患者分组的 Rad-DINO 对照实验

本轮仅使用原始 train.csv。11055 名患者先按固定 seed=20261105 的哈希顺序随机分组：20%患者封存用于最终核验，其余患者划分三折。同一患者的全部图像、检查保持在同一分区；标签仅用于检查各分区十类AUC均可定义，不搜索分区种子。原始数据、旧模型和已交付提交文件保持独立。

每折分别从已固定SHA-256的公开 yaLLMan/rad-dino-chexpert 初始化，复制十类分类头，仅训练最后两个block、layernorm、分类头。固定518预处理、主干学习率1e-5、weight decay=1e-4、有效batch16、三轮余弦衰减；只评估最后一轮，避免逐轮选择。

- A：分类头学习率1e-3。
- B：分类头学习率1e-4；这是A/B间唯一的优化参数变化。
- 每次训练同时维护EMA(decay=0.999)，只在成功的优化器更新后更新。
- 先比较A/raw与B/raw；B仅在三折平均增量≥0.001且至少两折增量>0时晋级。随后仅比较胜出配置的raw与EMA，使用相同规则。最终相对A/raw也必须达到此规则。
- 开发集没有候选通过时，保留封存集，不生成其模型评估分数。
- 有候选通过时，先锁定配置，再分别重新训练A/raw和该候选，训练患者仅含开发集；固定三轮后对封存集进行一次预定比较。要求增量≥0.001且1000次配对患者bootstrap增量95%区间下界>0，才记录为本轮核验支持收益。

该流程评估的是训练配置相对新训练A基线的改进，不直接等于相对旧七模型融合的收益。旧本地检查点训练过整个train，不可用于新封存集的独立比较。上游公开预训练数据与匿名本地数据是否重叠仍未知，该流程不能消除上游重叠，也不能保证测试分数提高。

运行代码和公开初始文件、原train元数据、分区、实验配置均保存指纹和代码快照；Python及主要包版本保存并检查。图像记录绝对路径、大小和纳秒修改时间，逐阶段检查，未对全部图像计算内容哈希。各阶段记录独立日志、进度和完成状态；已完成阶段仅在产物哈希匹配时复用。官方valid和test不参与本轮选择，现有测试提交不自动替换。
