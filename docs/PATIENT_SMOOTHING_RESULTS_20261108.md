# 固定患者聚合实验结果（2026-11-08）

唯一候选的训练患者完整 OOF 与官方 valid AUC 点估计均提高，但没有通过预先固定的 valid 晋级门槛。保留当前 CXR-LT 模型及用户反馈线上 **78.98** 的原 CSV；本轮没有读取 test 概率，没有导出新 test CSV，没有线上候选分数。

## 固定方案与晋级规则

协议为 [PATIENT_SMOOTHING_PLAN_20261108.md](PATIENT_SMOOTHING_PLAN_20261108.md)：`q = 0.75 * p + 0.25 * mean_patient(p)`。同患者检查等权、包含自身、singleton 精确保留；train OOF、valid、test 独立聚合，不跨 split。不训练模型或头，不搜索系数、按类权重或阈值。系数有 2026-11-04 同一官方 valid 上的历史探索来源，已在结果前披露。

OOF 要求相对当前和旧融合各提高至少 0.001，至少三组提高；通过后才能评估 valid。valid 对两项基准分别要求点增益至少 0.001、1,000 次患者配对 bootstrap 的描述性 95% 差值区间下界大于零、至少 950 次完整十类 replicate。seed 固定为 20261108。结果出现后未调整门槛或系数。

## 结论范围

患者聚合候选的 valid 点估计是本次已完成研究中更高的观察值，**0.8335505264 是保留模型的 valid AUC，不能继续称为所有已完成候选的最高点估计**。OOF、official valid、线上评分对应不同人群，不能混为同一排行榜。历史选优复用了本地验证人群，bootstrap 区间为描述性结果，不校正该选择偏差；区间跨零也不等价于“候选完全无效”。

本轮证据支持继续保留已反馈线上 78.98 的文件，不能据此声称患者聚合线上必然提高或降低。医学预训练来源仍完整保留，规则限制见 [官方评分口径](OFFICIAL_SCORING_20261108.md)。持续提升目标保持 active，本轮固定候选已结束。
